<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| guest browser → public catalog/detail | Untrusted slugs, filters, and add-to-cart form values enter public/client UI. |
| authenticated browser → cart/checkout actions | Client submits quantities, product ids, and failure checkbox; server actions are authoritative. |
| authenticated browser → `/orders/[id]` | A URL id must not cross the ownership boundary into rendered order data. |
| admin browser → `/admin/orders` | GET filters and status forms cross into admin page/action code. |
| mock email outbox → order link | Stored `order_id` is rendered as a navigation target and must not expose a second inbox or arbitrary URL. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-08 | Tampering | product/cart/checkout client forms | high | mitigate | Server actions revalidate UUID, quantity, stock, current price, session, and failure boolean; client state never authorizes a purchase. |
| T-03-09 | Information Disclosure | `/orders/[id]` | high | mitigate | Query includes `user_id = currentUser.id`; malformed, unknown, unauthenticated, and non-owned ids converge on the same not-found response (D-11). |
| T-03-10 | Elevation | admin order UI/actions | high | mitigate | Existing proxy/layout/session gate plus action re-check; lifecycle allowlist prevents arbitrary status/refund/restock requests. |
| T-03-11 | Information Disclosure | public product catalog | low | accept | Product names, prices, descriptions, stock display, and categories are intentionally public storefront data; customer/order data is not rendered there. |
| T-03-12 | Tampering | cancel dialog replay | medium | mitigate | Per-row pending state, conditional server transition, requestSubmit interception, and transaction idempotency reject ready/cancelled repeats without a second refund/restock. |
| T-03-13 | Injection | GET filters/order link | medium | mitigate | Allowlist status/category/price values and UUID order filters before SQL; use parameterized fragments and fixed internal route construction. |
| T-03-SC | Tampering | npm/pip/cargo installs | low | accept | No package-manager or registry install is part of this UI plan; it uses existing shadcn/Radix wrappers only. |
