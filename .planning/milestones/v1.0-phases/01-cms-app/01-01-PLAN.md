| client → /api/uploads | Untrusted multipart payload; route re-checks session, type, and size server-side (never trust client validation) |
| app → Neon (raw SQL) | All user-influenced values (search q, slugs, ids) flow into tagged-template SQL — parameterization is the only injection defense |
